Bewertungsregeln und frühere Bewertungen

So liest du den Bewertungsverlauf

Jede Speicherung erzeugt eine neue Version (Revision). Ein Entwurf ist eine Notiz und zählt noch nicht als Urteil. Für die Ergebnisse gilt die jüngste abgeschlossene, gültige und zum gesicherten Code passende Bewertung. Eine Korrektur überschreibt die frühere Bewertung nicht.

Welche Regeln gelten?

T1 prüft automatisch den Start im eingefrorenen Laravel-Gerüst. T2–T4 prüfst du mit den obigen Anleitungen. T5 prüft gemeinsame Grundlagen und erlaubte Änderungen; semantische Zweifel werden von dir geklärt.

Ein belegter Verstoß gegen ein Laravel-Kriterium setzt den funktionalen Gesamtwert auf 0. Ein fehlender Beleg ist keine Nullbewertung. Code-Stil oder persönliche Vorstellungen von „idiomatischem Laravel“ sind keine zusätzlichen Kriterien.

Die Anleitungen folgen der gebundenen Rubrik {{ rubric.code if rubric else '' }}. Dateien, Hashes, Werkzeugversion, dein Name und der Zeitpunkt werden mit dem Urteil gespeichert.
